## 🎯 Description

The **Woo Custom Thank You Page** plugin allows you to set a custom "Thank You" page after checkout in WooCommerce. You can define a **global thank you page** for all products or override it at the **individual product level**. Perfect for personalized messaging, promotions, upsells, or redirection.

---

## ✅ Features

- 🔄 Global Thank You Page setting.
- 📦 Product-level custom Thank You Pages.
- ⚙️ Admin settings panel integrated under WooCommerce.
- 🚚 Seamless redirect after checkout.
- 💼 Lightweight, secure, and optimized.

---

## 🛠️ Installation

1. Download the plugin or clone the repository.
2. Upload the plugin to `/wp-content/plugins/woo-custom-thank-you-page/`.
3. Activate it from the **Plugins** menu in WordPress.
4. Go to **WooCommerce → Thank You Page** to configure the plugin.

---

## ⚙️ Configuration

### Global Thank You Page

- Navigate to **WooCommerce → Thank You Page**.
- Select a page to use as the global Thank You page.
- This page applies to all products unless a custom one is set at the product level.

### Product-Specific Thank You Page

- Edit any WooCommerce product.
- In the **Thank You Page Redirect** box, choose a specific page.
- This setting overrides the global option for that product only.

---

## 🚀 Usage

- When a customer completes a purchase, the plugin checks if any product in the order has a custom thank you page.
- If found, it redirects to that page.
- If no product-specific page is defined, it uses the global page.
- If neither is set, WooCommerce's default Thank You page is shown.
